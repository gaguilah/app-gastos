# Referencias de diseño

Cuatro pantallas de ejemplo generadas con Stitch (modo oscuro, vista de computador). Son una **guía de forma**: composición, jerarquía, densidad y tokens. No definen contenido ni funciones; eso lo define `docs/plan.md`.

| Archivo | Pantalla de la app |
| --- | --- |
| `ExampleDashboard.html` | Panel principal |
| `ExampleGastos.html` | Gastos y filtros |
| `ExampleCategorias.html` | Gestión de categorías |
| `ExampleResumen.html` | Reportes y resumen del período |

Qué tomar y qué no de los ejemplos está en `.claude/skills/diseno-ui/SKILL.md`. Los tokens extraídos, en `.claude/skills/diseno-ui/references/tokens.md`.
